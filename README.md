# Rabbit Import — 1688 MCP server and buying agent for ChatGPT and Claude

Rabbit Import (rabbitimport.com) is a buying agent on 1688, China's domestic wholesale marketplace, that works inside ChatGPT and Claude.
Search 1688 in your own words, from a link or a photo, order through Rabbit, and get your goods checked in China
and shipped to 23 countries, the US included.

This repository documents the hosted server. There is no code to install.

## Connect

- Endpoint: `https://rabbitimport.com/mcp` (Streamable HTTP)
- Auth: OAuth (sign in with your Rabbit account)
- Official MCP Registry: `com.rabbitimport/rabbit`

Step-by-step:
- ChatGPT: https://rabbitimport.com/en/guides/add-connector-to-chatgpt.html
- Claude: https://rabbitimport.com/en/guides/add-connector-to-claude.html

## What your assistant can do

- Search 1688 in your own words, from a 1688 link, or from a photo.
- Read a full listing in English: photos, video, variants, specifications, prices by quantity.
- Get a quote for your quantity, then the link to order: you pay in Rabbit, Rabbit buys on 1688.
- Follow orders and parcels, see warehouse photos taken in China, get invoices.
- Receive goods you bought yourself: Rabbit checks them and ships them on.

Shipping is paid once the parcel is weighed.
